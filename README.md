# Sean's Game-Icons

A black-bordered and geometrically-adjusted repackaging of icons from [game-icons.net](https://game-icons.net) for FoundryVTT.

The black border and white interior design allows you to use FoundryVTT's tile tinting features to change the icons to any color you want, making them highly customizable for your games.

## Setup in FoundryVTT

You can install this module in two ways: via `git clone` or by downloading the repository's ZIP file.

### Option 1: Git Clone

1. Navigate to your FoundryVTT `modules` folder:
   ```bash
   cd FoundryVTT/Data/modules
   ```

2. Clone the repository directly into the `modules` folder:
   ```bash
   git clone https://github.com/seansbox/seans-game-icons.git
   ```

3. That's it! The icons will be available in the `icons` folder of this module.

### Option 2: Download the ZIP

1. Download the latest ZIP of the repository from the [GitHub releases page](https://github.com/seansbox/seans-game-icons/releases).

2. Extract the contents of the ZIP file into your FoundryVTT `modules` folder.

3. Once extracted, you should see the `seans-game-icons` folder inside `FoundryVTT/Data/modules`.

4. Restart FoundryVTT to complete the setup. The icons will be available in the `icons` folder of this module.
